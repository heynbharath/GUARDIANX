# GuardianX — Elderly Remote Safety

A premium, responsive single-page concept website and interactive UI demo personalized for Sunaina Mohapatra (USN: ENG24CT0058).

## Included
- `index.html` — standalone website, styling, SVG illustrations, and demo interactions.
- Responsive landing page, platform features, response architecture, family dashboard, and project/academic section.
- Simulated inactivity and fall-alert interactions.
- Clear disclosures that no real sensor, guardian, doctor, or ambulance integrations are connected.

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload `index.html` and this `README.md` to the repository root.
3. Import the repository at https://vercel.com/new.
4. Deploy as a static site. No build command or framework preset is required.

## Important
This is a concept/UI prototype only. Dashboard values and events are simulated. It is not a medical device or emergency service and must not be used to make real safety decisions.
