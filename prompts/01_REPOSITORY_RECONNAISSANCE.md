# Antigravity Task 01 — Repository Reconnaissance

Read `00_START_HERE/ANTIGRAVITY_MASTER_PROMPT.md` and the handoff documents first.

Task:
1. Inspect the current repository without deleting or rewriting files.
2. Identify framework, package manager, routes, existing GuardianX site, commands, deployment configuration, tests, and gaps.
3. Compare existing code against the PRD and acceptance criteria.
4. Propose the smallest safe implementation plan with file-by-file changes.
5. Identify unknowns and decisions that should remain open.
6. Do not claim features are implemented unless you can point to code and tests.
Return a concise audit and plan before implementation.
